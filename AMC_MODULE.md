# Pest Mantra AMC / Service Contracts

Premium recurring-service module added to the existing Quotation + Invoice project.

- Company/branch scoped MongoDB contracts
- Monthly, bi-monthly, quarterly, half-yearly, annual and custom schedules
- Automatic visit plan generation
- Active / paused / expired / cancelled lifecycle
- One-click scheduled visit -> real Project/Job
- Duplicate visit-job protection
- Renewal creates a new follow-on contract
- Contract value, visit KPIs, expiry visibility, search/filter
- Responsive Admin UI and sidebar integration

A generated AMC visit uses the existing Project service and therefore keeps the current project authorization and operational workflow.
