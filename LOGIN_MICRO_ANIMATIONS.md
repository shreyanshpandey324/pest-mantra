# Login Micro Animations

The Admin login screen now includes restrained enterprise-style motion only on the presentation layer.

- Soft shell fade/settle on load
- Centered Pest Mantra brand fade-down
- Hero title/subcopy fade-up
- Staggered feature card entrance
- Gentle ambient background drift and glow pulse
- Login heading/card fade-up
- Input focus lift/glow
- Login button hover lift, sheen and arrow motion
- Feature card hover lift
- `prefers-reduced-motion` is respected

No authentication, API, backend, MongoDB, session, or role logic was changed.
No animation library dependency was added; the motion is CSS-only.
